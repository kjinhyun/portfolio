+

프로젝트 개요

대상: 현대차 와이퍼 멀티펑션 스위치 (양산)
기간: 약 1~2개월
역할: 주관 엔지니어
협업: 설계팀 협업

기구 구조 및 문제

  • 레버-브라켓 힌지 구조, 내부에 라쳇과 액시얼 인장스프링 배치
  • 스프링 중앙부가 라쳇 절도산에 접촉하여 활시위 형태로 조작력 생성
  • 스프링이 중립 위치로 복귀 시 라쳇과 SRC 충돌하여 소음 발생

해석 방법

  • 솔버: ABAQUS Explicit
  • 총 6개 강체 파트 모델링, 부품 간 접촉 조건 설정
  • 3단계 순차 스탭 해석: 스프링 초기 셋팅 → 레버 초기 당김 → 실제 작동(라쳇 회전 → 장력 변화 → 복귀)
  • 각 스탭 앞 단계의 동적 해석 결과(속도, 변형, 응력)를 후속 스탭 경계조건으로 매핑

소음 저감 검토

  • 소음을 직접 지표화 불가 → 고정부 반력(reaction force) 및 접촉 하중 기준 상대 비교
  • 라쳇 절도산 형상(각도, 곡률) 변수화하여 복수 설계안 비교

성과

  • 고정부 반력 약 40% 저감
  • 정해석만으로 파악 불가능했던 기구 작동 시 동적 응력 집중부를 사전 규명
  • 반력 기반 상대 비교 방법론을 통해 소음 원인을 수치화하여 객관적으로 판단
  • 최적 절도산 형상 도출로 소음 저감 개선안 제시, 설계팀에 반영
